# aheadcane.github.io

The public site of Ahead Cane, the iPhone app for white-cane users: the home page, the beta request form (`beta/`), the privacy policy (`privacy/`) and support (`support/`). The App Store listing and the app's Settings link to `privacy/` and `support/`, so those two paths stay put. GitHub Pages serves this branch's root as it is; there is no build.

The beta form posts to the `ahead-ask` Worker, whose source and origin allowlist are in [Jog-sama/AHEAD](https://github.com/Jog-sama/AHEAD) (`worker/`). The app itself is also in that repo.
